
# AI-Powered GitHub Commit & Comment Analysis Agent

An AI-powered application that analyzes GitHub repository activity.

## Planned Features

- Retrieve GitHub commits and changed files.
- Analyze repository comments and suggestions.
- Use CrewAI agents to summarize development activity.
- Track previous execution timestamps.
- Generate reports about new repository activity.

## Technology Stack

- Python
- CrewAI
- GitHub REST API
- Requests
- python-dotenv
